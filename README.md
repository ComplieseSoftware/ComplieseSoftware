# Hi there, welcome to Compliese Software! 👋

I'm a **14-year-old** C++ developer passionate about low-level graphics programming, real-time rendering, and game engine architecture.

Currently building **[CoreEngine](https://github.com)** — a lightweight 2D/3D game engine written from scratch in modern **C++20** and **OpenGL 3.3 Core**.

---

### 🚀 Featured Project

[![CoreEngine](https://shields.io)](https://github.com)

- **Zero-Overhead Architecture:** Decoupled static library (`.lib`) with a clean public API.
- **High Performance:** Custom GPU state caching and dynamic VBO updates (**6,500+ FPS** in 2D benchmarks).
- **From First Principles:** Built directly on top of GLFW, GLAD, and stb_image to deeply understand how engines work under the hood.
